## Владение документацией

- Общие концепции core, жизненный цикл аккаунта, локальное состояние и сквозные контракты безопасности находятся в `docs/core/`.
- Руководство пользователя плагина, его настройки, схема полей `kw-*`, permissions, движение данных/сети, опасные действия и ограничения принадлежат директории `crates/plugins/<id>/` самого плагина.
- Инструкции браузерного расширения хранятся рядом с расширением; инструкции web-клиента — рядом с web-приложением.
- Поддерживайте английскую и русскую версии вместе. При изменении кода, permissions manifest, схемы поля или пользовательской операции обновляйте руководство-владелец.
- README проекта — краткий обзор и навигация, а не копия инструкций каждой интеграции.
