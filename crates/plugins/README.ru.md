# Руководства плагинов

**Языки:** [English](README.md) · Русский

Каждое руководство принадлежит плагину и находится рядом с его manifest/исходниками. В нём описываются специфичные поля, permissions, движение данных, настройки, операции и ограничения; общая архитектура находится в [`docs/core/`](../../docs/core/README.ru.md).

| Плагин | English manual | Русское руководство |
|---|---|---|
| SSH | [README](ssh/README.md) | [README.ru](ssh/README.ru.md) |
| HashiCorp Vault | [README](hashicorp/README.md) | [README.ru](hashicorp/README.ru.md) |
| Kubernetes | [README](kube/README.md) | [README.ru](kube/README.ru.md) |
| Администрирование Vaultwarden | [README](vaultwarden/README.md) | [README.ru](vaultwarden/README.ru.md) |

При изменении кода, permissions в manifest, собственного поля `kw-*` или поведения интерфейса синхронно обновляйте соответствующие английское и русское руководства.
